# BrandSync — Figma to After Effects

Official documentation and support for the free BrandSync Figma plugin.

BrandSync helps motion designers transfer selected Figma designs to Adobe After Effects, preserving editable layers where supported and using PNG fallbacks for complex artwork.

## Documentation

- [Privacy policy](PRIVACY.md)
- [Getting started and troubleshooting](GETTING-STARTED.md)

## Availability

The Figma plugin is free. Importing designs into After Effects requires the separate commercial BrandSync After Effects extension, planned for release on aescripts + aeplugins. The companion is currently in pre-release; public download information will be added once available.
