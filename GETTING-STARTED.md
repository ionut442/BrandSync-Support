# Getting started with BrandSync

## Requirements

- Figma Desktop with a Figma Design file.
- Adobe After Effects and the compatible BrandSync After Effects extension for importing designs.
- Both applications on the same computer for automatic transfer.

The Figma plugin is free. The commercial companion extension is currently in pre-release and is planned for distribution through aescripts + aeplugins. Public download and installation information will be added when available.

## Automatic transfer

1. Install the BrandSync Figma plugin and the compatible After Effects extension when available.
2. In the After Effects extension, open **Figma Import → Automatic**.
3. Run BrandSync in Figma and enter the pairing code shown in After Effects.
4. Select your design and choose **Send to After Effects**.
5. Check the import result in After Effects. Complex elements may be imported as PNG assets rather than editable native layers.

## Manual transfer

Select your design in Figma and choose **Download JSON**. Open Figma Import in the compatible After Effects extension, select Manual, and import the downloaded file.

## Troubleshooting

If the connection is unavailable, make sure both apps are open on the same computer and the automatic import receiver is active. If pairing is invalid, use **Pair a different Figma** in After Effects to generate a new code. If a transfer times out, check whether an import completed in After Effects before retrying to avoid duplicates.

If you need help, email **oproiu.ionut@gmail.com** with the Figma and After Effects versions, operating system and a description of the issue. Do not include pairing codes, tokens or confidential artwork.
